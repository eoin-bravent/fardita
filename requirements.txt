# lxml is the ONLY hard dependency: the DITA/HTML parsers (the `build` + chunking path) need it.
# Everything else in fardita is Python standard library — the reference pass, `verify`, and `dates`
# read JSON stores and import no third-party packages, and the default USAi.gov LLM backend is
# stdlib-only (urllib). So `lxml` alone makes every verb work.
lxml>=4.9
